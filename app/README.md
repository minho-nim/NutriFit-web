# NutriFit

식사 기록, 영양 목표 관리, 맞춤형 메뉴 추천, 음식 도감과 펫 육성 앱입니다.

## API 키 없는 배포

기본 배포는 정적 웹 앱입니다. `npm ci` 후 `npm run build`로 생성되는 `dist/`를 호스팅합니다. 음식 검색·직접 입력·영양 계산·추천·펫 기능은 브라우저에서 작동하며 외부 AI API 키를 사용하지 않습니다. AI 사진 분석은 기본 비활성화되어 있습니다.

### GitHub Pages

소스와 빌드 결과는 공개 저장소 `minho-nim/NutriFit-web` 하나에서 관리합니다. 사이트 주소는 `https://minho-nim.github.io/NutriFit-web/`입니다. 로그인 없이 접속할 수 있습니다.

업데이트 시 `npm run deploy:pages`를 실행하면 `dist/` 빌드 결과가 저장소 루트에 반영됩니다. Pages는 main 브랜치 루트를 게시합니다. `/NutriFit-web/` 경로에 맞춰 빌드하며 로컬 개발과 일반 정적 빌드의 기본 경로는 `/`입니다.

앱 소스는 `app/` 아래에 있습니다. 브라우저가 받는 HTML·JS·CSS는 공개 파일입니다. 이 배포에서는 외부 AI API를 사용하지 않습니다.

## 로컬 실행

Node.js 22.12 이상에서 `npm ci` 후 `npm run dev`를 실행합니다. 개발 서버는 `http://localhost:3000`입니다. 정적 빌드는 `npm run build` 후 `npm run preview`로 확인합니다.

## 데이터와 비밀값

식사·프로필·펫 데이터는 브라우저 LocalStorage에 저장됩니다. 다른 브라우저로 옮길 때는 앱의 데이터 내보내기/가져오기를 사용하세요. GitHub로 사용자 기록이 자동 전송되지 않습니다.

`.env*`는 Git에서 제외하며 값이 없는 `.env.example`만 공유합니다. AI 기능을 추후 활성화할 때에는 서버 환경변수 `GEMINI_API_KEY`에 키를 설정하고 서버 API를 제공해야 합니다. 키를 `VITE_*` 변수에 넣으면 안 됩니다. `VITE_ENABLE_AI_PHOTO=true`는 사진 분석 화면을 활성화하는 공개 설정이며 키가 아닙니다.

## 펫 성장

식사·추천 보상은 합산 하루 최대 60 EXP입니다. 쓰다듬기는 경험치를 주지 않고 하루 한 번 친밀도를 올립니다. 일일 한도는 브라우저의 로컬 날짜를 기준으로 초기화되며 저장됩니다.

최근 7일의 아침·점심·저녁에 기록한 식재료를 바탕으로 푸른 정원·튼튼한 모험가·곡물 친구·다채로운 셰프 계열로 진화합니다. 같은 끼니의 같은 식재료 계열은 한 번만 반영됩니다. 식사량이나 반복 등록으로 방향 점수를 늘릴 수 없습니다. 방향은 다음 단계로 진화할 때 결정되고, 이전에 발견한 모습은 계속 도감에 남습니다.

음식 도감 화면의 `펫 성장 도감` 탭과 밥친구 대화의 성장 화면에서 총 17가지 형태를 확인할 수 있습니다. 미발견 형태는 실루엣과 물음표로만 표시됩니다. 기존 저장의 현재 모습은 유지되며 미래 모습과 다른 계열은 자동 공개되지 않습니다.

### 포만감과 미식 돼지 계열

포만감은 오늘의 아침·점심·저녁·간식을 펫과 처음 나눌 때 각각 40씩 올라갑니다. 같은 끼니의 여러 음식은 한 번의 급식으로 계산하며 칼로리나 음식 무게로 포만감을 늘리지 않습니다. 과거 날짜의 기록은 급식으로 계산하지 않습니다.

포만감은 접속 여부와 관계없이 시간당 12씩 자연 감소합니다. 대화·쓰다듬기·추천 평가·새로운 성장 이야기 시작으로 포만감을 낮출 수 없습니다. 급식 후 75 이상이면 그 식사의 추가 EXP는 절반, 95 이상이면 추가 EXP는 0입니다. 이미 쌓은 경험치와 사람의 식사 기록은 유지됩니다. 기존 일일 60 EXP 한도도 그대로 적용됩니다.

이번 성장 이야기의 최근 7일 급식 중 포만감이 75 이상이 된 식사가 3회 이상이면 다음 진화는 포근한 미식 돼지 계열로 이어집니다. 2~4단계는 먹보 꼬마·복슬복슬 요리사·미식 돼지왕이며, 돼지 계열 완전 성장 후 새 이야기를 시작하면 1단계 아기 꿀꿀이를 만날 수 있습니다. 새 이야기에서는 이전 세대의 식사 기억이 진화 방향을 결정하지 않지만 현재 포만감과 당일 급식 제한은 유지됩니다.

4단계·1,000 EXP를 채우면 확인 후 새로운 성장 이야기를 시작할 수 있습니다. 경험치는 0, 단계는 1로 돌아가지만 이름·성격·친밀도·도감·함께한 식사 기록과 오늘의 보상 한도는 유지됩니다.

펫 로직과 도감 공개 조건 검사: `npm run test:pet`.

## 현재 기능 연결성 점검

수정한 연결과 다음 버전 보류 범위는 [기능 연결성 검토](docs/feature-flow-review.md)에 정리했습니다. 전체 회귀 검사는 `npm test`로 실행합니다. 과거·미래 날짜 기록은 저장되지만 오늘의 펫 성장 보상을 주지 않습니다. 추천의 먹음 평가는 식사 기록과 경험치를 이중 지급하지 않으며 같은 메뉴의 평가 보상은 하루 한 번만 반영됩니다.
