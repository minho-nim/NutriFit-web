# 현재 버전 기능 연결성 검토 — 2026-10-26 완료

## 마무리한 연결

| 흐름 | 발견한 문제 | 수정 |
| --- | --- | --- |
| 대화 → 식사 기록 | 아침·저녁·간식 버튼도 점심으로 열림 | 대화의 끼니를 기록창에 전달 |
| 대화 → 추천 | 분류는 대사에만 반영 | 국물·고단백·샐러드·가벼운 식단 실제 후보 필터, 분류 해제 |
| 포만감 반응 → 도감 | 성장 도감 버튼이 음식 도감을 엶 | 성장 하위 탭을 직접 지정 |
| 성장 단계 배지 → 성장 화면 | 배지를 눌러도 대화 탭이 열림 | 기존 성장·성격 탭 직접 열기 |
| 상단 버튼 → 상세 화면 | 취향·알레르기 버튼이 상위 화면까지만 이동 | 분석 탭·알레르기 설정 직접 열기 |
| 홈 → 추천 기록 | 홈만 별도 이름·영양값·알레르기 기준 사용 | 공통 추천 엔진·기록 변환 사용 |
| 대체 추천 → 기록·평가 | 불안정한 ID, 원래 메뉴의 탄수화물·지방·평가 대상 사용 | 선택한 메뉴 전체 정보와 고정 ID 사용 |
| 끼니 → 추천 | 간식도 큰 식사 후보 사용 | 아침·간식 후보량 구분, 기존 식품 데이터 재사용 |
| 기록 → 도감 | 동기화마다 과거 횟수에 재가산, 다른 중량 영양값 평균 | 실제 로그로 횟수 재계산, 최근 기록량과 중량 명시 |
| 도감 → 재기록 | 150g으로 즉시 저장하면서 영양값은 다른 기준 사용 | 중량·끼니·알레르기를 확인하는 기존 기록창 연결 |
| 조합 → 기록·성장 | 음식 개수를 반복 횟수로 표시, 성장 시 첫 음식만 반영, 마지막 보상만 표시 | 조합 반복 횟수 계산, 전체 음식으로 방향 결정, 합산 반응 |
| 추천 → 취향·진화 | 식재료와 조리법이 기록에서 유실 | 식재료·조리법·맛 스냅샷 보존 |
| 별점 → 취향 | 기록·도감 별점이 따로 저장되고 학습에 미반영 | 별점 동기화와 학습 가중치 반영 |
| 과거·미래 날짜 → 보상 | 오늘이 아닌 기록에도 성장 보상 지급 | 식사 기록만 저장, 급식·성장 보상 없음 |
| 기록 삭제 → 다음 진화 | 지운 음식의 방향 점수가 남음 | 유효 기록으로 다시 계산, 기존 경험치·발견 모습·급식 제한 유지 |
| 기록 → 함께한 식사 | 여러 접시가 여러 끼로 계산 | 날짜별 끼니로 계산, 같은 끼니 친밀도 반복 보상 제한 |
| 평가 → 성장 | 새 평가 ID로 같은 메뉴 보상 반복, 먹은 기록과 이중 경험치 | 메뉴별 일일 평가 보상 제한, 먹음 평가는 별도 EXP 없음 |
| 포만감 → 평가 보상 | 평가로 포만감의 EXP 제한 우회 가능 | 포만감 제한을 평가 EXP에도 적용 |
| 체중 → 목표 | 현재 체중만 변경되고 목표 계산은 예전 값 | 최신 체중이면 재계산, 수동 목표는 보존, 과거 체중은 현재값을 덮어쓰지 않음 |
| 저장·복원 | 구조가 잘못된 JSON도 성공 처리 | 쓰기 전 백업 형식 검사, 도감 재계산, 쓰기 실패 시 복구 시도 |
| 날짜 변경 | 과거 영양 요약이 현재 펫 대화에 섞임 | 펫은 오늘 기준, 영양·기록은 선택 날짜 기준, 자정 갱신 |

## 현재 배포 범위

식사 검색·직접 입력, 영양 합계, 취향 추천·평가, 기록·조합, 음식 도감, 펫 대화·성격·이름, 일일 성장·포만감·식재료 진화·실루엣 도감, 프로필·체중·알레르기, 로컬 저장·백업을 연결한다. 기존 예시 데이터는 유지한다.

공개 버전은 API 키 없이 동작한다. 사진 AI는 의도적으로 비활성화되어 있다. 서버의 AI 분석·코칭 API는 현재 공개 버전의 사용 흐름에 연결하지 않는다.

## 다음 버전으로 보류한 항목

사용자 지정 범위에 따라 이번 변경에는 다음 기능을 추가하지 않았다.

1. 돌봄 기억
2. 자기만의 행동
3. 짧은 놀이와 탐험
4. 집 꾸미기
5. 성장 이벤트와 추억 카드 (기존 단계 상승 알림만 유지)

## 확인 방법

- `npm test`: 펫 성장 및 화면 간 데이터 흐름 회귀 검사
- `npm run lint`: TypeScript 검사
- `npm run build:pages`: GitHub Pages 배포 빌드
- `npm run dev`: 로컬 실행, 브라우저에서 추천→기록·대화→추천·성장 도감·상세 화면 연결 확인
