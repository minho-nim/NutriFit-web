# 가볍게 함께하는 밥친구 — 2026-10-26

## 이번 버전

- 집 꾸미기·재화·탐험 게임은 추가하지 않는다. 식사 기록과 펫의 교감에 집중한다.
- 식사 기억은 실제 식사 기록·별점에서 가져온다. 어제 음식, 반복해서 먹은 음식, 높은 별점을 준 음식을 대화와 추억 화면에 표시한다. 기록을 삭제하면 해당 기록을 기억의 근거로 사용하지 않는다.
- 성격과 포만감, 좋아한 음식에 따라 반기기·가볍게 뛰기·흔들거리기·쉬기를 표시한다. 동작 줄이기 설정을 존중한다.
- 공을 세 번 받는 짧은 교감 놀이를 제공한다. 완료한 날은 저장되며 하루 한 번 친밀도만 최대 3 올라간다. 경험치와 포만감은 바꾸지 않는다.
- 실제 다음 단계로 성장한 순간에 모습·날짜·세대·함께 기록한 음식 최대 세 가지를 추억 카드로 저장한다. 이후 세대에도 남고 기존 JSON 백업에도 포함된다. 이전 버전의 과거 진화 날짜는 추정해서 만들지 않는다.
- 기존의 하루 60 EXP, 식재료 진화, 시간으로만 줄어드는 포만감, 미발견 실루엣 도감은 유지한다.

## 화면 구성

홈은 밥친구 → 식사 기록 버튼 → 영양 요약 → 추천 → 끼니 기록 순서다. 성장 세부 수치는 접힌 영역에서 확인한다. 대화·놀이·추억은 홈에서 바로 열고 도감은 밥친구 카드 상단에 둔다.

하단은 홈·기록·기록하기·추천·마이의 익숙한 위치로 고정한다. 별도의 떠다니는 기록 버튼을 없애고 주요 버튼과 날짜 이동 버튼은 손가락으로 누르기 쉽게 만든다. 흰 카드, 부드러운 회색 배경, 파란 핵심 버튼, 여유 있는 간격을 공통으로 사용한다. 기존 화면의 개발 식별자와 지나치게 작은 글씨를 정리한다.

모달은 배경 스크롤을 막고 키보드 포커스를 유지하며 Esc로 닫는다. 탭을 바꾸면 첫 화면으로 이동한다. 모든 데이터는 기존과 같이 브라우저에 저장되며 별도 AI API 키는 필요하지 않다.
